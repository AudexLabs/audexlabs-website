About Audex

Audex is a desktop application that introduces a unified, multimodal architecture to music creation. It moves beyond traditional music notation and analysis software by combining professional typesetting, a free vector graphics canvas, and intelligent workflow assistance into a single environment.

Software features

  • Standard & hybrid notation

    The platform provides comprehensive standard typesetting tools while allowing users to import graphics and fixed media directly onto a vector canvas, enabling the creation of custom noteheads, cutaway scores, and hybrid graphical layouts.

  • Semantic AI assistant

    An integrated Large Language Model (LLM) trained on musical syntax enables dialogue-based score editing and acts as a smart proofreader for instrument playability, functioning strictly as an assistant rather than an automated music generator.

  • Advanced tuning & microtonality

    Audex offers full graphic and audio support for complex microtonality and global tuning systems, including extended just intonation, the Turkish Makam system, and Helmholtz or Sagittal accidentals.

  • Smart MIDI & playback integration

    The software utilizes machine learning for intelligent articulation mapping, automatically assigning notated techniques to the correct MIDI values, and supports flexible output via MIDI, MPE, and OSC.

  • Interdisciplinary & spatial tools

    Users can map physical movement like Labanotation, sync multiple timelines with SMPTE timecode, and design 3D spatial audio panning directly within the visual score.

  • DAW compatibility

    To fit seamlessly into existing workflows, the platform’s core functions are available as standard VST3, AU, and AAX audio plugins.

  • Global formatting & accessibility

    The architecture supports diverse text directions, including right-to-left and top-to-bottom formatting, and includes a native voice-to-text interface for fully accessible, hands-free operation.

About the funded project

Audex Labs is developing a desktop environment that brings professional music typesetting, a free vector canvas and notation-aware workflow assistance together in one application. The goal of the funded project is to carry this architecture from prototype to a release that composers, publishers and performers can test in daily work, covering standard and hybrid notation, microtonality and global tuning systems, spatial and interdisciplinary scoring, and accessible, hands-free operation. Results so far include the unified score architecture and the feature set described above; the financial support of the European Union through ESF Plus finances the development work behind them.
